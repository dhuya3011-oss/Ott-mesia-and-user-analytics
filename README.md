# 📺 OTT Media Analytics Platform

End-to-end analytics for a streaming (OTT) platform: viewership KPIs, content ROI, cohort retention,
churn prediction and an interactive Streamlit dashboard. All data is **synthetic** (generated by
`src/data_generator.py`), so the insights validate the pipeline, not real user behaviour.

**Live demo:** _add your Streamlit Community Cloud link here_

## Features
- **KPI engine:** MAU, DAU, monthly ARPU, monthly and lifetime churn, completion rate, watch hours, MRR
- **Filters:** plan, region, device, date range (Streamlit sidebar)
- **Genre and content analysis:** revenue attributed by each subscriber's watch-time share (no double counting)
- **Content ROI:** attributed revenue vs production cost per title, best and worst performers
- **Cohort retention heatmap** by join month
- **Churn model:** Random Forest on pre-snapshot features (no leakage), adjustable decision threshold
- **Retention campaign simulator:** turns model precision and recall into a net rupee impact
- **SQL scripts** for schema, KPIs, cohorts and revenue attribution in `sql/`

## Data scale
About 10,000 subscribers, 500 titles, ~270,000 watch sessions and ~136,000 monthly revenue rows.

## Churn model
Snapshot 1 Jul 2025; label = churns within the next 180 days; features use only data before the snapshot
(recency, sessions in the last 30 days, total sessions, completion, tenure, revenue, plan).

| Metric | Result |
| --- | --- |
| Test ROC-AUC | ~0.73 |
| 5-fold CV ROC-AUC | ~0.75 |
| Recall at chosen threshold | ~70% |
| Precision at chosen threshold | ~15% |

Recall is prioritised: a retention offer is cheap, a lost subscriber is not. Precision is low, so the
simulator shows when a campaign is still profitable.
